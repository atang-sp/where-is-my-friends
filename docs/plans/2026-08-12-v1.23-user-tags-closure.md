## 本次变更（同意制印象标签）

新增成员印象标签：任何成员可向他人提议自由文本标签，但提议在被标签人批准前保持私密；
批准后标签出现在成员卡片上，其他成员可公开赞同。

1. 同意模型：提议即存但仅提议人与被标签人可见 → 被标签人在收件箱批准/拒绝 → 批准后才公开。
2. 隐私不变量：pending 标签永不进入公共序列化；已批准标签仅对双方无屏蔽/静音且可查看资料
   的用户展示；提议人匿名；禁止自标签与自赞同。
3. 开关：`where_is_my_friends_user_tags_enabled` 默认 `false`，本次部署后已手动开启。
4. 分析：6 个白名单事件（`user_tag_proposed/approved/rejected/removed/endorsed/endorsement_removed`），
   不含标签文本、目标 ID 或位置。
5. 表：`where_is_my_friends_user_tags` 与 `where_is_my_friends_tag_endorsements`（FK 全部 bigint，
   适配 CI 与生产的 10 亿级主键序列）。

## 观察点（T0 起）

- 印象标签使用量：`user_tag_proposed`、`user_tag_approved`、`user_tag_endorsed` 的聚合漏斗，
  以及收件箱页 `/where-is-my-friends/tags` 的访问，全部只以聚合形式进入 `/debug-stats.json`。
- 回滚条件：站点 5xx 持续超过 10 分钟、主要路由不可用或插件页面白屏时，恢复
  `app.yml.pre-v1.23.0-20260812T121910Z` 并按回滚备份重建；回滚后 `user_tags_enabled`
  回到未开启状态（备份创建于开启之前）。
